# Profile avatars

Drop the four mascot PNGs (the ones attached in the design feedback) here:

- `avatar-1.png` — frog mascot
- `avatar-2.png` — pink dog mascot
- `avatar-3.png` — yellow / brown dog mascot
- `avatar-4.png` — purple cat mascot

The Profiles section renders each user profile through `<img src="/avatars/avatar-N.png" />` cycling through these four files. When a file is missing the gradient + emoji fallback shows.
